# Changelog

## 0.1.0 — 2026-10-25

Initial independent React implementation: generic validated documents; conditional questions; prerequisite-aware answer review; local Zustand workspace; Radix dialogs; Motion transitions; contextual notes and drafts; session exports; fictional English/Persian examples; tests and project documentation.

This is a new application format. It does not silently import personal data from the earlier standalone prototype.

The initial release also includes styled shadcn/Radix selects, independent persisted UI language, bidirectional popup alignment and isolated progress ratios. Repository presentation adds dedicated concept artwork, a minimal starter document, issue/PR templates and release notes.
