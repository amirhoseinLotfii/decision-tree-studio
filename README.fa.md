# استودیوی درخت تصمیم

ابزاری مستقل با ری‌اکت برای تبدیل دادهٔ ساختاریافته به سؤال، گزینه، شاخهٔ شرطی و تصمیم ثبت‌شده.

[English](README.md) · [قالب داده](docs/data-format.md) · [معماری](docs/architecture.md) · [وضعیت آزمون](docs/QA.md)

این پروژه به موضوع خاصی مثل فروشگاه یا دسته‌بندی وابسته نیست. سؤال‌ها، گزینه‌ها، مثال‌ها، دلایل، منابع و وابستگی‌ها را در یک فایل جیسون تعریف می‌کنید و برنامه نمودار و فرم پاسخ را می‌سازد.

## امکانات فعلی

- نمودار تعاملی با جابه‌جایی، زوم، نقشهٔ کوچک و نمایش وابستگی‌ها.
- سؤال‌های مستقل، پیش‌نیازها و شرط «همه» یا «حداقل یکی».
- نمایش جداگانهٔ سؤال، مثال، گزینه‌ها، مزایا، ریسک‌ها، نتیجه و منبع.
- پیشنهاد پیش‌فرض برای مطالعه انتخاب می‌شود؛ تا ثبت نکنید پاسخ محسوب نمی‌شود.
- مسیر نامرتبط فقط توضیح می‌دهد کدام پاسخ قبلی باعث کناررفتن آن شده است.
- تغییر پاسخ قبلی یا تعریف سؤال می‌تواند پاسخ‌های وابسته را نیازمند بازبینی کند.
- ذخیرهٔ محلی پاسخ‌ها، پیش‌نویس گزینه و یادداشت، تنظیمات و پروژه‌ها.
- بازگردانی تغییر، انجام دوباره، جست‌وجو، فیلتر، بازنشانی جلسه و خروجی کامل.
- یادداشت روی گره یا خط اتصال با نگه‌داشتن کلید آلت و کلیک.
- رابط فارسی و انگلیسی، راست‌به‌چپ، فونت محلی، حالت روشن و تیره و انیمیشن با رعایت کاهش حرکت.

## اجرا

نسخهٔ ۲۴٫۱۵ یا جدیدتر نود لازم است. در پوشهٔ پروژه نصب وابستگی‌ها و سپس اجرای برنامه را انجام دهید:

```sh
npm ci
npm run dev
```

برای بررسی کد، آزمون‌ها و ساخت نسخهٔ نهایی:

```sh
npm run check
```

## روش پاسخ‌دادن

موضوع‌های بالای درخت جایگزین هم نیستند؛ همهٔ سؤال‌های مرتبط باید پاسخ بگیرند. سؤالِ وابسته پس از پاسخ معتبر به پیش‌نیازش قابل ثبت می‌شود. شاخهٔ نامرتبط از پیشرفت کنار می‌رود. انتخاب «بعداً» تصمیم را باز نگه می‌دارد.

در منو می‌توانید نمونهٔ فارسی را باز کنید یا فایل خودتان را وارد کنید. واردکردن سند با شناسهٔ قبلی، پاسخ‌ها را برای بازبینی حفظ می‌کند؛ واردکردن خروجی کامل جلسه، همان جلسه را بازیابی می‌کند. برای پروژهٔ مستقل شناسهٔ جدید بگذارید.

## نگهداری داده

داده‌ها در حافظهٔ محلی همان مرورگر و همان نشانی نگه داشته می‌شوند. تغییر پورت، مرورگر یا پروفایل، فضای جداگانه‌ای دارد. این ذخیره رمزنگاری یا پشتیبان دائمی نیست؛ قبل از پاک‌کردن دادهٔ مرورگر خروجی بگیرید. خطای خواندن یا پرشدن حافظه نمایش داده می‌شود و نسخهٔ خراب خودکار بازنویسی نمی‌شود.

این نسخه حساب کاربری، همگام‌سازی، پژوهش خودکار یا تأیید منابع ندارد. نمونه‌ها ساختگی و پیشنهاد نویسنده هستند. داده‌های شخصی پروژهٔ قبلی در این مخزن قرار ندارند.

## حدود بررسی

آزمون‌های کدی و ساخت نسخهٔ نهایی اجرا می‌شوند. بررسی ظاهری در مرورگر واقعی و آزمون دستی موبایل و صفحه‌خوان هنوز در گزارش آزمون به‌عنوان بررسی‌نشده ثبت شده‌اند. محدودیت تعداد گره، تضمین سرعت برای نمودار بسیار بزرگ نیست.

مجوز کد پروژه ام‌آی‌تی است؛ مجوز مستقل فونت و کتابخانه‌ها نیز باید رعایت شود.
