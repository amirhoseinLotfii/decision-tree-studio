# Repository presentation assets

- `docs/media/hero.png`: README concept artwork, 1400 × 650.
- `docs/media/social-preview.png`: social-preview upload artwork, 1280 × 640.
- `docs/workspace-concept.svg`: editable conceptual diagram from the initial introduction.

These are illustrations with fictional content, not runtime screenshots or evidence of a browser audit.

GitHub social preview is configured separately in repository Settings → General → Social preview. The PNG is supplied for that upload; committing it alone does not change the repository's Open Graph image.

The repository metadata, topics, README, examples, templates and release notes are maintained alongside the code. Do not advertise roadmap items as implemented or include private session data in presentation assets.
