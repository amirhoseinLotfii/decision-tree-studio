# Roadmap

## Implemented in 0.1

Generic document import, conditional decision engine, dependency review, diagram/list views, source attribution, note drafts, annotations, local project sessions, undo/redo, exports, English/Persian and Motion transitions.

## Next: validate the experience

- Real-browser responsive, keyboard, touch and screen-reader acceptance matrix.
- Profile large graphs, long labels and deep condition networks.
- Persist viewport per document and provide clearer large-graph navigation.
- Add multi-tab change detection and explicit storage recovery tools.

## Candidate features, not promises

- Visual question/option authoring with schema-aware validation.
- Library packaging with configurable renderers and host-owned persistence.
- Additional locales, configurable themes and document migrations.
- Selective answer review/diffs when a document changes.
- Optional adapters for collaboration, with explicit ownership and conflict rules.

No automatic AI research or paid dependency is required for the current application.

Runtime demonstration datasets were removed in 0.1.1. Start with an empty workspace and import host-owned data.
