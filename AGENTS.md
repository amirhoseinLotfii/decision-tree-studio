# Agent instructions

This is an independent generic project. Do not modify another workspace or copy its private data into this repository.

Before editing, inspect Git status and current source. Keep user changes. Keep the decision engine pure, references validated, examples fictional and strings safe as plain text. State shape, storage keys and document/session formats are public compatibility boundaries.

Use real tests, lint and build. Behavior changes require tests. Never disable validation, rules or failures to pass a gate. Never claim browser verification from unit tests, DOM tests or HTTP availability.

Preserve unreadable backups and user sessions. Document any migration. Keep reduced-motion, keyboard dismissal, RTL and source-kind distinctions. Use local fonts with redistribution rights.

Do not publish private research or session exports. Check the target GitHub account before creating/pushing a repository. Publishing authorization is separate from a code-review claim.

Repository publication defaults to public as requested by the owner. Ship application code, not user datasets or session exports. Do not bundle or automatically create demo projects. Keep only minimal synthetic test fixtures and explanatory documentation snippets needed to verify and describe the software.
